# Aisha Abdirahman Abukar — Portfolio

React + Vite + Tailwind CSS + Framer Motion single-page portfolio.

## Run locally
npm install
npm run dev

## Build
npm run build

## To personalize
- Replace public/aisha-placeholder.svg usage: drop the real portrait at
  public/aisha-photo.jpg and change `photo` in src/data/profile.js to
  "/aisha-photo.jpg".
- Add a CV PDF at public/Aisha-Abdirahman-Abukar-CV.pdf to make the
  "Download CV" button work (path is set in src/data/profile.js -> cvFile).
- All text content lives in src/data/profile.js.
